# Problem Statement

As software teams increasingly adopt AI coding assistants like IBM Bob and GitHub Copilot to accelerate development, a new, dangerous category of technical debt has emerged: **AI-Generated Semantic Code Bloat.**

When AI generates features or refactors code, it often introduces dependencies, configuration flags, or helper functions. However, when those features are later modified or deleted, the associated architectural artifacts are frequently left behind. Over time, enterprise codebases accumulate:

1. **Ghost Dependencies:** Packages installed in `package.json` that are no longer imported anywhere in the application logic.
2. **Duplicate Logic:** Semantically identical code blocks generated by AI in different services, completely bypassing DRY (Don't Repeat Yourself) principles.
3. **Dead Configurations:** Obsolete keys inside `config.json` or `.env` files that have zero active execution paths.

### Why Standard Linters Fail
Standard linters (like ESLint) and traditional static analysis tools are designed to catch syntax errors or unused variables within a *single file*. They do not possess the repository-wide semantic context required to safely identify that a global configuration key is obsolete, or that a dependency is entirely unused across hundreds of microservices.

### The Cost to the Enterprise
This invisible bloat has severe consequences:
- **Security Risks:** Ghost dependencies still receive vulnerability alerts (CVEs) and increase the attack surface, despite serving no purpose.
- **Maintenance Costs:** The financial impact of maintaining larger Docker containers, slower CI/CD pipelines, and bloated cloud storage.
- **Developer Confusion:** Engineers waste hours trying to understand the purpose of a "legacy helper" function, only to realize it has been a zombie for 12 months.

There is a desperate need for a tool that acts as an "MRI Machine" for the codebase—capable of finding the exact coordinates of this hidden debt, and orchestrating an AI Agent like IBM Bob to surgically liquidate it.
